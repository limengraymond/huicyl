晖常语录 H5 V11 完整部署版

本版共收录 217 条语录、25 篇文章，语录、文章和首页更新提示均由 data.js 统一管理。

本版更新：
1. 首页内容统计自动显示文章数量，新增或删除文章后自动更新
2. 首页搜索卡片下方增加品牌化的最新更新提示卡片
3. “已收录文章”右上角增加“新春寄语合集”入口
4. 合集仅展示 data.js 中标记为 isNewYearGreeting 的文章
5. 支持无外部链接文章的站内全文阅读，并保留外部原文链接兼容
6. 保留分类导航、出处年份导航、分享图、访问密码和移动端适配功能

访问设置：
1. 网站已启用前端访问密码
2. 验证成功后，当前浏览器 7 天内免登录
3. 如需修改密码或免登录时长，请编辑 auth.js 顶部的 ACCESS_PASSWORD 或 ACCESS_DAYS
4. 此方式用于阻止普通访客进入，不属于服务端安全认证

部署时请直接选择本文件夹作为项目根目录。后台导出的 data.js 可直接覆盖本文件夹中的同名文件。
