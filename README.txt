晖常语录 H5 V8 完整部署版

这是在 V7 基础上增加“近期文章”站内全文阅读能力后的完整部署版，共收录 208 条语录、6 篇近期文章。

本版更新：
1. “近期文章”列表统一展示文章标题和收录时间
2. 支持没有外部链接的文章直接收录正文
3. 有站内正文的文章可点击进入全文阅读页
4. 原有带链接文章继续打开外部原文，保持兼容
5. 新增《深耕机构战略 坚守本心精进——张总在机构2026Q2季度会上的讲话》全文
6. 保留 V7 的全部分类调整、AI语录、出处年份导航、分享图、访问密码和移动端适配功能

访问设置：
1. 网站已启用前端访问密码
2. 验证成功后，当前浏览器 7 天内免登录
3. 如需修改密码或免登录时长，请编辑 auth.js 顶部的 ACCESS_PASSWORD 或 ACCESS_DAYS
4. 此方式用于阻止普通访客进入，不属于服务端安全认证

部署时请直接选择本文件夹作为项目根目录。部署后进入“近期文章”，即可查看站内全文文章和原有外部链接文章。
